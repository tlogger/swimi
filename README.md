# Swimi (스위미) - 전국 자유수영장 찾기 웹앱

내 위치 또는 지정 일자/시간/장소 기준으로 즉시 자유수영이 가능한 수영장을 탐색하고, 25m/50m 레인 규격 및 50분 수영/10분 휴식시간 여부 확인과 함께 카카오맵 내비게이션으로 원클릭 연결하는 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **실시간 자유수영 가능 여부 및 휴식시간 판정 (24x7 매트릭스)**:
   - 24시간 × 7일 매트릭스 기반 실시간 상태 판정.
   - 50분 수영 / 10분 휴식제(`50_10`)와 연속 자유수영(`continuous`) 구분.
   - 현재 시각 기준 `운영중(초록)` / `휴식시간(노랑/주황, 50분~정각 사이 대기)` / `종료·휴무(회색)` 3단계 시각화.
2. **카카오맵 연동 & 마커 시각화**:
   - **25m 레인**과 **50m 국제규격 레인** 아이콘 구분 표시.
   - 오늘 운영 중인 수영장은 명칭 라벨 노출, 미운영 수영장은 회색 표시 및 명칭 숨김.
   - 검색창 실시간 연동 (예: '화성', '전주', '동탄' 입력 시 해당 지역 수영장 실시간 필터 및 지도 포커싱).
3. **카카오내비 길안내 & 원클릭 전화걸기**:
   - 상세 바텀시트에서 **'카카오내비'** 클릭 시 모바일/웹 카카오맵 길찾기로 즉시 연동.
   - 수영장 안내데스크 직통 전화 걸기 연동.
4. **상세 필터 & 리스트 보기**:
   - 날짜 증감 `+/-` 버튼 및 `오늘` 버튼.
   - 평일 / 토요일 / 일요일 / 공휴일 요일별 필터링.
   - 수영장 목록 모달: '가나다순', '가까운순' 정렬 및 '운영중만 보기' 토글.
5. **수영장 상세 정보 및 생생 후기**:
   - 레인 길이, 레인 수, 수심, 24시간 시간대별 가능 여부 타임라인 바.
   - 일일 입장료 (성인/청소년/어린이, 관외 요금 별도 구분).
   - 주차 가능 여부 및 무료 지원 시간, 샤워실/수질 관리 등급, 발한실, 걷기레인, 공용 킥판 허용 여부.
   - 전국자유수영 카페 이용 후기 요약 및 평점.

## 🚀 빠른 시작

### 설치 및 로컬 실행
```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행 (포트 3000)
npm run dev

# 프로덕션 빌드
npm run build
```
